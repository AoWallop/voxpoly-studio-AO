# ทำเสียงให้เข้ากับท่า

เสียงจะรู้สึกใช่ เมื่อมันลงตรงเฟรมที่ร่างกาย*ทำอะไรบางอย่าง*พอดี ให้หาเฟรมเหล่านั้นจากข้อมูลท่า ไม่ใช่ใช้หูเดา
(เวอร์ชัน 1.1 จะมีเครื่องมือหาจังหวะเสียงและตัวเล่นเสียงตาม cue หน้านี้คือวิธีคิดและรูปแบบไฟล์)

## 1. หาจังหวะ

จากตำแหน่งกระดูกทุกเฟรม (ดู [ทำ Animation จาก FBX](animation.md))

| เสียง | จังหวะ | วิธีจับ |
|---|---|---|
| ฝีเท้า | เท้าแตะพื้น | ความสูงเท้าต่ำสุด **และ** ความเร็วเกือบเป็นศูนย์ |
| สวิง / ฟึ่บ | ช่วงสวิงเร็วสุด | ความเร็วสูงสุดของมือ / ปลายอาวุธ (เริ่มเสียงก่อนจุดพีคนิดหนึ่ง) |
| กระแทก | สวิงหยุด | ความเร็วปลายอาวุธตกฮวบหลังจุดพีค |
| คำราม / เสียงพูด | ปากอ้า | มุมกรามเกินค่าที่ตั้ง · ความยาว = อ้าค้างนานแค่ไหน |
| ล้มกระแทกพื้น | ตัวถึงพื้น | ความสูงสะโพกต่ำสุดหลังร่วงเร็ว |
| กระพือปีก | จังหวะตีลง | ความเร็วแนวดิ่งของข้อมือปีกติดลบมากสุด |

## 2. ไฟล์ cue

1 ไฟล์ JSON ต่อโมเดล cue แยกตามท่า หน่วยวินาที:

```json
{
  "clips": {
    "attack": { "len": 1.8, "cues": [ { "t": 0.42, "sfx": "whoosh" }, { "t": 0.61, "sfx": "impact" } ] },
    "walk":   { "len": 1.0, "loop": true, "cues": [ { "t": 0.12, "sfx": "step" }, { "t": 0.62, "sfx": "step" } ] }
  }
}
```

- **สุ่มเสียง:** ตั้งชื่อเป็นกลุ่ม (`step`) แล้วสุ่ม 1 จากหลายไฟล์ทุกครั้ง เสียงเดิมซ้ำๆ จะฟังเป็นเครื่องจักร
- **ท่าที่ถูกตัด / เร่ง:** ตัดช่วง `[a, b]` ออก หรือเร่งช่วงไหน ให้เลื่อน cue หลังจากนั้นเท่ากัน
  เก็บไฟล์ cue เป็น*เวลาของท่าต้นฉบับ*เสมอ แล้วค่อยแปลงตอนเล่น ต้นฉบับจะใช้ได้ตลอด

## 3. เสียงต่อเนื่อง

คำรามยาวหรือเสียงชาร์จพลัง ไม่ควรเป็นไฟล์เดียวที่ยืดออก ให้ใช้ **ต้นเสียง + ช่วงวน + ท้ายเสียง**
เริ่มที่ cue แล้ววนช่วงกลางแบบไร้รอยต่อระหว่างที่ท่าค้าง (ปากอ้า · กำลังชาร์จ) จากนั้นปล่อยท้ายเสียงตอนท่าจบ
ความยาวช่วงค้างเอามาจากท่า (ปากอ้าเกินค่าที่ตั้งนานแค่ไหน)

## 4. Sound Map ให้ทีม

โปรแกรมเมอร์ของ engine อ่านตารางง่ายกว่าอ่านโค้ด:

| ท่า | เวลา (วิ) | เสียง | หมายเหตุ |
|---|---|---|---|
| attack | 0.42 | whoosh | สุ่ม 1 ใน 3 |
| attack | 0.61 | impact | |
| roar | 0.30 → 2.10 | roar (sustain) | วนระหว่างปากอ้า |

engine ใส่เป็น Animation Event ตามเวลาในตารางได้เลย

## 5. ทำเสียง

ใช้แหล่งไหนก็ได้ (อัดเอง · คลังเสียง · AI สร้างเสียง) ถ้าเครื่องมือต้องใช้ API key ให้เก็บคีย์ไว้ใน `.env`
(git ไม่ติดตาม) **ห้าม**ใส่ไว้ในสคริปต์ที่ commit ขึ้นไปเด็ดขาด
