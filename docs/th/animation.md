# ทำ Animation จาก FBX

วิธีศึกษาท่าจากไฟล์ FBX แล้วสร้างใหม่บนโมเดลของเราเองใน three.js แม้โครงกระดูกจะคนละแบบ
(เวอร์ชัน 1.1 จะมีเครื่องมือพร้อมใช้ทุกขั้น หน้านี้คือวิธีคิด)

## 1. อ่านการเคลื่อนไหวเป็นตัวเลข

เปิด FBX ใน Blender (แบบไม่มีหน้าต่าง) ไล่ทุกเฟรม แล้วเขียน**ตำแหน่งโลกของหัว/ปลายกระดูกทุกชิ้น**ลง JSON
ใช้ตำแหน่ง ไม่ใช้มุม เพราะมุมขึ้นกับการตั้ง roll และท่าตั้งต้นของแต่ละ rig ส่วนตำแหน่งไม่ขึ้น

ดูอะไรก่อน:
- **ความยาวและ fps** — ความยาวจริงของท่าหลังตัดแล้ว
- **root motion** — ตัวละครเคลื่อนที่ไหม (ส่วนใหญ่ตัดทิ้ง แล้วให้เกมเป็นคนเลื่อนตัวละครเอง)
- **จังหวะแตะ** — เฟรมที่เท้า / มือ / ปลายหาง ต่ำสุดและช้าสุด = แตะพื้น
- **จุดพีค** — ความเร็วสูงสุดของมือหรือปลายอาวุธ = จังหวะโดน · ปากอ้ากว้างสุด = คำราม

## 2. วัด "ท่าทางรวม" อย่าก๊อปมุมกระดูก

โครงคนละแบบ ก๊อปมุมไปตรงๆ จะพัง ให้วัด**ช่องควบคุม**ไม่กี่ช่องของทั้งตัวแทน โดยเทียบกับเฟรมแรกของท่ายืน และวัดตามทิศที่ลำตัวหัน

| ช่อง | วัดจาก |
|---|---|
| หมุนตัว · เดินหน้า/ข้าง | root / สะโพก |
| ความสูงตัว · เชิดตัว | สะโพก · อก |
| ยก/ส่ายคอ-หัว · อ้าปาก | อก → หัว · กระดูกกราม |
| ตำแหน่งมือ / ข้อมือปีก | ตำแหน่งข้อมือเทียบลำตัว **ความสูงวัดจากพื้น** (ไม่ใช่จากสะโพก) |
| ยกหาง / กวาดหาง | แบ่งหางเป็น 2 ท่อน: โคนแทบไม่ขยับ ปลายสะบัด |
| เท้า | เท้าไหนยก ยกตอนไหน สูงแค่ไหน |

จากนั้นโมเดลของเรา*บวก*ค่าช่องเหล่านี้ทับท่ายืนของตัวเอง จังหวะยังเป็นของ Animator ต้นฉบับ ซึ่งมักเป็นส่วนที่ดีที่สุดอยู่แล้ว

## 3. บทเรียนที่พิสูจน์แล้ว

- **คิด IK ตามแกนโลก** ขา เท้า กรงเล็บ ต้องคำนวณกับแกนขึ้นของโลก ถ้าตัวเชิดขึ้น 30–40° แล้วคิด IK ตามแกนลำตัว เท้าจะจมพื้น
- **หักมุมเชิดตัวออกจากมุมหาง** ไม่งั้นตอนตัวเชิด หางจะจมพื้น
- **ท่าค้างต้องมีช่วง "นิ่ง" ที่ยังหายใจ** ไม่ใช่แช่เฟรมเดียว
- **ตัดหรือเร่งเป็นช่วง** (`[จาก, ถึง]`) แทนการทำท่าใหม่ แล้วเลื่อนจังหวะเสียงตามเท่ากัน (ดูหน้าเสียง)
- **อย่าใส่สปริงที่คอ** "ให้ดูมีน้ำหนัก" จะดูเป็นหัวเด้ง จังหวะต้นฉบับมีน้ำหนักอยู่แล้ว
- **QC ด้วยตัวเลขและมุมบน**: เก็บความสูงข้อเท้า / หัว / ปลายอาวุธทุก 0.05 วิ และดูจากด้านบน มุมข้างซ่อนความผิดด้านข้าง
- ถ้าจังหวะต้นฉบับดีอยู่แล้ว **ปรับให้เข้ากับตัวเราก่อน** ค่อยออกแบบทับเฉพาะส่วนที่ตัวเราต่างจริงๆ

## 4. Export ท่าของเราเอง

ท่าที่กำหนดในโมเดล (`ANIMS`) จะ export เป็น `<Name>@<ท่า>.fbx` ท่าละไฟล์ และตรวจด้วย `tools/fbx_check.py`
