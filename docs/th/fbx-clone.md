# ลอก FBX — คัดลอกโมเดลที่มี rig เข้า three.js แบบเป๊ะทุกจุด แล้วปรับสัดส่วน

[English](../en/fbx-clone.md)

ถ้ามีตัวละครที่ Artist ปั้นมาแล้ว (FBX ที่มีกระดูกและท่า) เครื่องมือนี้จะคัดลอก**จุดยอด หน้า UV น้ำหนัก กระดูก และทุกเฟรมของท่า**
เข้า three.js พิสูจน์ว่าตรงต้นฉบับจริง แล้วให้**ปรับสัดส่วนด้วยแถบเลื่อน** เช่น หัวใหญ่ ขายาว แขนอวบ โดยท่ายังเล่นได้
ค่าแถบเลื่อนชุดหนึ่งบันทึกเป็น **preset** เพื่อเอาไปใช้ในเกมได้

ข้อ 1 คือวิธีใช้เครื่องมือ ข้อ 2–5 คือความรู้เบื้องหลังว่าต้องทำอะไรให้ถูกถึงจะลอกได้เป๊ะ และระบบสัดส่วนทำงานอย่างไร
ควรอ่านก่อนแก้โค้ด

## 1. เครื่องมือ (v2.5)

```bash
# 1. ใส่ไฟล์ใน workspace/fbx/ (แบบ Unity ดีที่สุด):
#    Hero.fbx            rig + mesh (ท่า T หรือ A)
#    Hero@Idle.fbx       ไฟล์ละ 1 ท่า (มี mesh อยู่ข้างในหรือไม่ก็ได้ แต่ถ้ามีจะตรวจความเป๊ะได้)
#    Hero_Texture.png    texture ที่ FBX อ้างถึง (ชื่อไฟล์ต้องตรงกัน)
npm run clone                    # แสดงรายชื่อตัวที่เจอ
npm run clone -- Hero            # → workspace/clones/Hero.json + เพิ่มรายการใน workspace/clones/index.json
npm run clone -- Hero --qc       # + ถ่ายภาพตรวจใน .qc/clone-Hero/ (แสงปกติ · cel shade · ท่า · เส้น topo · ปรับสัดส่วน · UV)
npm run serve                    # → เปิดแท็บ "ลอก FBX"
```

`npm run clone` จะพิมพ์**บทบาทกระดูก**ที่เดาไว้ (กระดูกไหนคือสะโพก เข่า ข้อมือ…) ต้องตรวจทุกครั้ง เพราะแถบเลื่อนขึ้นกับค่านี้
ถ้าผิดหรือหาไม่เจอ ให้แก้เองใน `workspace/clones/index.json` (`"roles"`) รันครั้งต่อไประบบจะเก็บค่าที่แก้ไว้

**หน้าเว็บ** (`clone.html?m=Hero`)

| ส่วน | ทำอะไร |
|---|---|
| ความเป๊ะ | จำนวนจุด/หน้า/สี่เหลี่ยม/กระดูก · ความสูง · **ท่าเทียบ Blender คลาดสูงสุดกี่ มม.** (ควรต่ำกว่า 0.01 มม.) |
| บทบาทกระดูก | บทบาทที่ใช้อยู่ ถ้าแถบเลื่อนไปขยับผิดส่วน ให้ดูตรงนี้ก่อน |
| ท่า | ท่า rest + ทุกท่า · ความเร็ว · เลื่อนดูทีละเฟรม |
| ชิ้น | ปุ่มเปิดปิดทีละ mesh เมื่อ FBX มีหลายชิ้น (ตัว ตา ผม…) |
| ดู | เปิดปิด texture · **เส้น Topo** = เส้นจริงของต้นฉบับ (สี่เหลี่ยมไม่มีเส้นทแยง) · กระดูก · หมุน |
| แสงเงา | การ์ตูน cel shade (ขั้นแสง เงาเข้ม เส้นขอบ มม.) หรือแสงปกติ |
| ปรับสัดส่วน | 17 แถบ (ข้อ 4) · ปุ่มค่าเดิม |
| Preset | ตั้งชื่อ + 💾 บันทึก → `workspace/presets/<โมเดล>/<ชื่อ>.json` · กดชื่อ preset เพื่อโหลด |
| UV / Texture | ผัง UV ทับ texture · ลายตรวจบนโมเดล · ⬇ เส้น UV โปร่งใส · ⬇ UV + สี · ⬇ OBJ ท่า rest (ไปวาดใน Substance / Blender) |
| ส่งออก | ⬇ GLB มี rig และทุกท่า **ตามสัดส่วนที่เห็นบนจอ** |

ลิงก์ตรง: `clone.html?m=Hero&preset=chibi` · `&shade=lit`
การบันทึก preset ต้องเปิดหน้านี้ผ่าน `npm run serve` (server เป็นคนเขียนไฟล์)

## 2. ลอกให้เป๊ะ (สคริปต์ Blender ทำอะไรบ้าง)

`tools/blender/fbx_clone.py` เปิด FBX ใน Blender แล้วเขียนเป็น JSON ธรรมดา ทุกข้อด้านล่างมีเพราะเคยข้ามแล้วผลออกมาผิดจนเห็นด้วยตา

**2.1 แกน** Blender ใช้แกน Z ขึ้น ส่วน three.js ใช้ Y ขึ้นและหน้าอยู่ +Z จึงหมุนคงที่ −90° รอบแกน X กับทุกจุดและทุกกระดูก:
`(x, y, z) → (x, z, −y)` ไม่มีการกลับด้านอื่น

**2.2 หน่วยและ scale 0.01 ที่ซ่อนอยู่** FBX ที่บันทึกเป็นเซนติเมตรจะมี scale 0.01 ติดมาที่ armature
จุดยอดคำนวณผ่าน world matrix ของ mesh ทั้งชุด จึงออกมาเป็นเมตร ส่วนกระดูกจะแยกส่วนแล้ว**ทิ้ง scale** เก็บแค่ตำแหน่งกับการหมุน
ถ้า scale ติดอยู่ในกระดูก ตอน export หรือ retarget ต่อ ความยาวกระดูกจะเพี้ยน 100 เท่าทันที

**2.3 กระดูกเก็บแบบเทียบพ่อ** ทุกกระดูก: world matrix ตอน rest แล้วแปลงเป็น `ตำแหน่ง = การหมุนพ่อ⁻¹ · (ตำแหน่ง − ตำแหน่งพ่อ)`
และ `การหมุน = การหมุนพ่อ⁻¹ · การหมุน` ซึ่งตรงกับที่ `THREE.Bone` ต้องการ การประกอบโครงจึงเป็นลูปธรรมดา

**2.4 หน้าเก็บตามที่ปั้นมา** สี่เหลี่ยมยังเป็นสี่เหลี่ยมใน JSON (นับแยก) สามเหลี่ยมยังเป็นสามเหลี่ยม three.js วาดได้แค่สามเหลี่ยม
จึงแบ่งสี่เหลี่ยมเป็น `(0,1,2)(0,2,3)` ซึ่งเป็นเส้นทแยงแบบเดียวกับ Blender แต่**หน้าดูเส้น Topo วาดขอบสี่เหลี่ยมจาก JSON**
จึงเห็น topology ที่ Artist ปั้นจริง ไม่ใช่เส้นที่เกิดจากการแบ่งสามเหลี่ยม

**2.5 รอยต่อ UV ทำให้ต้องแยกจุด** three.js ให้ 1 จุดมีได้ UV เดียว แต่ FBX เก็บ UV ต่อมุมของหน้า จุดที่อยู่บนรอยต่อ
(ตำแหน่งเดียวกันแต่ UV สองฝั่งไม่เท่ากัน) จึงแยกเป็นหลายจุด โดยใช้ `จุด:u:v` เป็นกุญแจ ลำดับและจำนวนจุดเดิมยังเก็บไว้ใน JSON
การตรวจข้อ 2.9 และเส้น Topo จึงใช้เลขจุดเดิม

**2.6 normal เกลี่ยบนจุดเดิม** ถ้าคำนวณ normal หลังแยกจุดตามรอย UV ทุกรอยต่อ UV จะเห็นเป็นรอยหักบนผิว
จึงเกลี่ยบนจุดเดิมก่อนแล้วค่อยคัดไปให้จุดที่แยก ผิวจึงเนียนเท่าต้นฉบับ

**2.7 น้ำหนักกระดูก: 4 อันดับแรก ปรับรวมเป็น 1** three.js รับได้ 4 กระดูกต่อจุด จึงเก็บ 4 ตัวที่แรงสุดแล้วปรับให้รวมได้ 1
mesh ที่ติดกับกระดูกโดยไม่มีน้ำหนักเลย (เช่น ดาบในมือ) จะได้น้ำหนัก 1 กับกระดูกนั้น

**2.8 ท่าเก็บทุกเฟรม ไม่ประมาณเส้นโค้งเอง** ทุกเฟรมของทุกท่าคำนวณใน Blender แล้วเก็บตำแหน่ง + quaternion เทียบพ่อของทุกกระดูก
เราไม่ได้เดาเส้นโค้งเอง จึงได้ครบทั้ง constraint, IK ที่อบไว้ในไฟล์ และการ interpolate แบบแปลกๆ

**2.9 พิสูจน์** Blender เขียนตำแหน่งของจุดตัวอย่าง 32 จุดที่กระจายทั่วตัว ตอนต้น กลาง และท้ายของทุกท่า
หน้าเว็บจัดท่าเฟรมเดียวกันใน three.js แล้ววัดระยะห่าง JSON ปัดทศนิยม 6 ตำแหน่ง (1 ไมครอน) ลอกถูกจะได้ประมาณ **0.002–0.05 มม.**
ถ้าเกิน 0.1 มม. แปลว่ามีข้อใดใน 2.1–2.8 พัง ต้องแก้ก่อน ห้ามปรับสัดส่วนต่อ

**2.10 หลาย mesh บน armature เดียว** รวมเป็น mesh เดียว แต่ละหน้าจำชื่อ mesh เดิมไว้ (กลุ่มหน้า) จึงเปิดปิดทีละชิ้น
และเลือกได้ว่าจะส่งออกชิ้นไหน

## 3. บทบาทกระดูก

แถบเลื่อนสัดส่วนไม่รู้จักชื่อกระดูก มันทำงานกับ**บทบาท** แล้ว `models/rigroles.js` เป็นคนจับคู่บทบาทกับกระดูกจริง

| บทบาท | หมายถึง | Mixamo | Unreal | Blender | แบบธรรมดา |
|---|---|---|---|---|---|
| hips | สะโพก | Hips | pelvis | pelvis | hip |
| spine / chest | กระดูกลำตัวชิ้นแรก / ชิ้นบนสุด | Spine / Spine2 | spine_01 / spine_03 | spine / chest | spine / chest |
| neck · head | คอ · หัว | Neck · Head | neck_01 · head | neck · head | neck · head |
| shoulder | ไหปลาร้า | LeftShoulder | clavicle_l | shoulder.L | left_shoulder |
| upperArm | **ข้อไหล่** | LeftArm | upperarm_l | upper_arm.L | left_arm |
| lowerArm | **ข้อศอก** | LeftForeArm | lowerarm_l | forearm.L | left_elbow |
| hand | **ข้อมือ** | LeftHand | hand_l | hand.L | left_wrist |
| upperLeg | **ข้อสะโพก** | LeftUpLeg | thigh_l | thigh.L | left_leg |
| lowerLeg | **เข่า** | LeftLeg | calf_l | shin.L | left_knee |
| foot | **ข้อเท้า** = ข้อถัดจากเข่า | LeftFoot | foot_l | foot.L | left_ankle |
| toe | โคนนิ้วเท้า | LeftToeBase | ball_l | toe.L | left_foot |

บทบาทคือ**ข้อต่อ** นับจากลำตัวออกไป จึงเป็นเหตุที่ "Leg" ของ Mixamo คือเข่า (เพราะมี `UpLeg` อยู่ข้างบน) แต่ใน rig แบบธรรมดาคือข้อสะโพก
ตัวเดาเช็กเรื่องนี้ให้แล้ว ถ้าชื่อไม่บอกอะไร มันจะไล่ตามสาย (ลูกของข้อศอกคือข้อมือ) บทบาทไหนหาไม่เจอ แถบเลื่อนที่ใช้บทบาทนั้นจะถูกซ่อน

## 4. ระบบปรับสัดส่วน

### 4.1 การเปลี่ยน 5 แบบ

| แบบ | อะไรขยับ | ใช้กับ |
|---|---|---|
| `size` | ขยาย/หดก้อนรอบกระดูก ลูกๆ ใหญ่ตาม | ทั้งตัว หัว มือ เท้า |
| `length` | ดันกระดูกออกห่างจากพ่อ (ท่อน**ของพ่อ**ยาวขึ้น) | คอ ลำตัว ไหล่ แขน ขา สะโพกกว้าง |
| `sizeOnly` | ขยายเฉพาะก้อนรอบกระดูกนี้ ลูกถูกชดเชยกลับขนาดเดิม (แต่ตำแหน่งข้อของลูกขยับตาม) | ข้อมือหนาขึ้นโดยมือไม่ใหญ่ |
| `girth` | ดันผิวออกจากแกนกระดูก (กระดูก → ลูกตัวแรก) ความยาวเท่าเดิม | อก เอว สะโพก ความอวบแขน/ขา |
| `belly` | เหมือน girth แต่ดันเฉพาะผิวที่หันไปข้างหน้า (+Z) | พุง |

### 4.2 แถบเลื่อน 17 แถบ

| แถบ | แบบ | บทบาท |
|---|---|---|
| ทั้งตัว | size | กระดูกรากทุกตัว |
| หัวใหญ่ · คอยาว | size · length | head |
| ลำตัวยาว | length | ทุกกระดูกตั้งแต่ spine ถึง neck |
| ไหล่กว้าง | length | upperArm |
| แขนยาว | length | lowerArm + hand (ต้นแขนและแขนท่อนล่างยาวขึ้น) |
| มือใหญ่ · ข้อมือ | size · sizeOnly | hand |
| อก · เอว · สะโพก | girth | chest · spine · hips |
| พุง | belly | spine + hips |
| แขนอวบ · ขาอวบ | girth | upperArm + lowerArm · upperLeg + lowerLeg |
| สะโพกกว้าง | length | upperLeg |
| ขายาว | length | lowerLeg + foot (ต้นขาและหน้าแข้งยาวขึ้น) |
| เท้าใหญ่ | size | foot |

ช่วงค่า 0.6–1.6 ถ้าสองแถบโดนกระดูกเดียวกัน ค่าจะคูณกัน รายการอยู่ใน `PROPORTIONS` ใน `models/clone.js`
เพิ่มแถบใหม่ = เพิ่ม 1 แถวตรงนั้น (และเพิ่มชื่อ `pr.<id>` ใน `i18n.js`)

### 4.3 การปรับสัดส่วนคำนวณยังไง (`C.reshape(mods)`)

1. **คำนวณจากต้นฉบับทุกครั้ง** สร้างโครงชั่วคราวจากท่า rest เดิม แล้วใส่การยืด/ขยาย แถบเลื่อนไม่ซ้อนทับผลรอบก่อน
   จะเลื่อนไปมากี่ครั้งก็ได้ แล้วกลับมาที่ 1.00 ได้ตรงต้นฉบับเป๊ะ
2. **ทำความอวบก่อน** ดันแต่ละจุดออกจากท่อนกระดูกที่จุดนั้นผูกอยู่ ตามสัดส่วน `น้ำหนัก × (girth − 1)`
3. **จุดยอดตามกระดูกตามน้ำหนัก** (linear blend skinning จาก rest เดิมไปโครงชั่วคราว) ข้อต่อจึงงอได้นุ่ม เพราะจุดใกล้ข้อศอกโดนดึงจากทั้งสองกระดูก
4. **เท้าแตะพื้นเท่าเดิม** เลื่อนทั้งตัวให้จุดต่ำสุดอยู่ระดับเดียวกับจุดต่ำสุดของต้นฉบับ
5. **อบลงโครงใหม่ที่ไม่มี scale** ข้อต่อได้ตำแหน่งใหม่ การหมุน rest เท่าเดิม และ scale ทุกตัวกลับเป็น 1 การเปลี่ยนแปลงย้ายไปอยู่ในจุดยอดแทน
   โครงที่ไม่มี scale ส่งออกเป็น GLB / Unity ได้สะอาด และ retarget ได้ตามปกติ
6. **สร้างท่าใหม่** ตำแหน่งในท่าเก็บเป็น*ระยะต่างจาก rest เดิม* แล้วบวกกลับบน rest ใหม่ การหมุนไม่แตะ ท่าเดินจึงยังเดินได้บนขาที่ยาวขึ้น
   (ถ้าเพิ่มท่าที่ทำด้วยโค้ดเองใน JSON ใส่ `scaleWithLegs` ให้ระยะยกสะโพกปรับตามความยาวขา และ `ground: 'lock' | 'clamp'` ให้วางเท้าแตะพื้นทุกเฟรม)

### 4.4 ข้อจำกัดที่ควรรู้

- **โมเดลที่ต่อจากชิ้นแข็ง** (แต่ละชิ้นผูกกระดูกเดียว 100%) พอใช้แถบแบบ `length` ยืด ข้อต่อจะแยกเป็นช่อง เพราะชิ้นขยับแต่ไม่ยืด
  ตัวละครที่ skin นุ่มไม่มีปัญหานี้ โมเดลแบบนี้ให้ใช้ `size` หรือทำ skin ที่ข้อต่อใหม่
- girth ใช้ท่อนจากกระดูกไปหา**ลูกตัวแรก** กระดูกที่ลูกตัวแรกชี้ไปด้านข้าง (เช่น กระดูกมือที่ลูกตัวแรกเป็นนิ้วโป้ง) จะบวมแปลกๆ
  มือจึงใช้ `size` ไม่ใช้ `girth`
- ค่าสุดขั้ว (ความยาวต่ำกว่า 0.7 หรือเกิน 1.4) จะยืดช่วงที่น้ำหนักผสมกันตรงข้อต่อ ให้ตรวจด้วยเส้น Topo
- ความเป๊ะวัดได้เฉพาะตอนสัดส่วนเดิม หน้าเว็บจะบอกไว้ระหว่างที่เลื่อนแถบ

## 5. Preset

preset คือไฟล์ JSON ที่ `workspace/presets/<โมเดล>/<ชื่อ>.json`

```json
{
  "base": "Hero", "source": "Hero.fbx",
  "sliders": { "headSize": 1.25, "legLength": 0.9, "armGirth": 1.1 },
  "mods": { "size": { "Head": 1.25 }, "length": { "LeftLeg": 0.9, "LeftFoot": 0.9 }, "girth": { "LeftArm": 1.1 } },
  "sizeCm": { "w": 52.1, "h": 46.3, "d": 12.0 },
  "shade": { "mode": "toon", "steps": 2, "dark": 0.55, "outlineMm": 2 },
  "name": "chibi", "model": "Hero", "saved": "2026-01-01T00:00:00.000Z"
}
```

- `sliders` = ค่าที่ตั้ง (ตามชื่อแถบ) · `mods` = การเปลี่ยนกระดูกที่แถบเหล่านั้นทำบน rig **ตัวนี้** เกมใช้ `mods` ได้เลยโดยไม่ต้องรู้จักแถบหรือบทบาท
- `sizeCm` = ขนาดกรอบหลังปรับ ไว้เทียบกับแบบในเอกสาร
- preset ของโมเดลเดียวกันคือตระกูลเดียวกัน เช่น "base" "chibi" "tall" "heavy" เก็บไว้ 1 ตัวต่อ 1 แบบรูปร่าง
  ตัวละครใหม่ให้เริ่มจาก preset ที่ใกล้ที่สุด ไม่ต้องเริ่มจาก 1.00

**ใช้ preset ในโค้ด three.js ของเราเอง**

```js
import { loadClone, modsFromSliders } from './models/clone.js';
const C = await loadClone('workspace/clones/Hero.json', { texture: 'workspace/fbx/Hero_Texture.png' });
const P = await (await fetch('workspace/presets/Hero/chibi.json')).json();
C.reshape(P.mods);                                        // หรือ: C.reshape(modsFromSliders(C.data.bones, C.roles, P.sliders))
scene.add(C.root);
const mixer = new THREE.AnimationMixer(C.root);
mixer.clipAction(C.clips.Idle).play();
```

หรือไม่ต้องคำนวณตอนเล่นเลย: เปิดหน้าเว็บ โหลด preset แล้วกด **⬇ GLB** ไฟล์ GLB จะได้ตัวใหม่พร้อม rig และท่า

## 6. เช็กลิสต์ก่อนเชื่อผลลอก

1. `npm run clone -- <Name>` ไม่มีบรรทัด `[WARN]` (ไฟล์ท่าขาดกระดูก · mesh ไม่มี UV)
2. บทบาทกระดูกถูกทุกช่อง (หรือรู้ว่าช่องไหนไม่มี)
3. ความเป๊ะต่ำกว่า 0.1 มม. ทุกท่า
4. เส้น Topo หน้าตาเหมือน mesh ที่ Artist ปั้น (ไม่มีสามเหลี่ยมแปลกพาดข้ามหน้า)
5. หลังปรับสัดส่วน เล่นทุกท่าจากมุมข้าง: เท้าแตะพื้น ข้อต่อไม่ยุบ
