# Topology

คำว่า "topo ยังไม่เรียบร้อย" พูดง่ายแต่แก้ยาก หน้านี้เปลี่ยนคำนั้นให้เป็นตัวเลขก่อน แล้วค่อยเป็นขั้นตอนทำงาน

## 1. วัด

```bash
blender -b --factory-startup -P tools/topo/audit.py -- out.json mine.glb reference.fbx
```

| ตัวเลข | ความหมาย | ค่าที่ดี |
|---|---|---|
| **เส้นล้น (5°)** | % สามเหลี่ยมที่ Limited Dissolve ลบได้โดยทรงไม่เปลี่ยน | < 5 % |
| **สามเหลี่ยมผอม** | ด้านยาวสุด² / (2·พื้นที่) > 10 — ที่ตาเห็นเป็น "ยับ / เป็นเศษ" | ผิวนอก < 10 % |
| **ขอบเปิด / non-manifold** | รู และรอยต่อที่ไม่ปิด | 0 (ยกเว้นตั้งใจให้เปิด) |
| **เกาะ UV · ความต่าง texel** | UV แตกแค่ไหน ความละเอียด texture สม่ำเสมอไหม | ใกล้ 1 |

ระยะคลาดจากต้นแบบ (วัดสองทาง หน่วย ซม.)

```bash
blender -b --factory-startup -P tools/topo/dump.py -- reference.fbx ref.json
blender -b --factory-startup -P tools/topo/dump.py -- mine.glb mine.json
python tools/topo/dist.py ref.json <ชื่อชิ้นต้นแบบ> mine.json
```
`ours->ref` = ผิวเรายื่นออกนอกต้นแบบแค่ไหน · `ref->ours` = ส่วนของต้นแบบที่เรายังไม่มี
ดูภาพประกอบด้วย: `tools/topo/render.py` (หลายมุม) และ `tools/topo/sheet.py` (wireframe 3 มุม · UV ทับ texture)

## 2. low-poly ที่ดีทำอะไร (บทเรียนที่พิสูจน์แล้ว)

1. **สามเหลี่ยมตามความโค้ง** ผิวเรียบใช้สามเหลี่ยมใหญ่ ถี่เฉพาะตรงที่โค้ง ตารางเท่ากันทั้งชิ้นทำให้เส้นล้นทุกที่
2. **งบ tri ไปที่ผิวนอก** งาน hard-surface ที่ดีใช้ tri กับผิวนอกที่มองเห็นมากกว่าด้านในของแผ่นราว 3–4 เท่า
3. **ขอบของหน้าต้องอยู่บนสันและขอบสี** หน้าที่คร่อมสันจะดูยับ ส่วนขอบสีที่พาดกลางหน้าต้องตัดเส้นเพิ่ม
4. **ห้ามขยับจุดออกจากระนาบเดิมเพื่อให้เส้นสวย** เกลี่ยเส้นขอบสีได้เฉพาะ*ในระนาบเดิม* หรือ*ตามแนวสัน* นอกนั้นหน้าเรียบจะบิด
5. **texture ที่อบเงาไว้ ให้แยกสีด้วยเฉด (hue) ไม่ใช่ความสว่าง** ทองในเงาจะกลายเป็น "เทา" ถ้าเทียบค่า RGB แต่เฉดสีไม่เปลี่ยนตามเงา
6. **normal คือจุดที่เราทำได้เกินต้นแบบ** flat ทุกหน้าบนโลหะโค้งดูราคาถูก ให้สันและขอบคม (hard) แล้วผิวโค้งใช้ weighted normal (soft) จะได้โลหะเนียนแต่รายละเอียดยังคม

## 3. สร้างโมเดลสตูดิโอจากต้นแบบ

```bash
npm run retopo -- ref/helmet.fbx Helmet ref/helmet_basecolor.png Helmet \
   --classes gold:25-65,blue:185-260 --snap gold
```

ขั้นตอน (`tools/topo/retopo.py`): ซอยผิวต้นแบบแบบไม่ทำให้มน → อ่านสีทีละจุด (mask ตามเฉดสี เบลอเฉพาะในเกาะ UV และเฉลี่ยข้ามรอยต่อ UV)
→ **ตัดหน้าตรงแนวที่สีข้ามค่า 0.5 พอดี** (ไม่ขยับจุดเดิมเลย) → สีที่อยู่ใน `--snap` ใช้สีเดียวทั้งแผ่นต้นแบบ (ลายนูนคม)
→ รวมเกาะสีเล็ก → เกลี่ยขอบสีในระนาบ ล็อกมุมแหลม → ยุบหน้าระนาบเดียวกันสีเดียวกัน → weighted normal (`tools/topo/normals.py`)

ได้ไฟล์ `workspace/retopo/Helmet_tris.js` เอาไปใช้ในโมเดล:

```js
import { fromTris } from '../models/kit.js';
import { themed } from '../models/themes.js';
import { TRIS } from './retopo/Helmet_tris.js';
export const info = { id:'helmet', name:'Helmet', exportName:'Helmet', set:'Armor' };
const ROLE = { base:'steel', gold:'trim', blue:'panel' };
export function build(theme){ return fromTris(TRIS, themed({ base:{ c:'#ccc' }, gold:{ c:'#da5' }, blue:{ c:'#35a' } }, ROLE, theme)); }
```

ตัวเลือกทั้งหมดดูในตารางของหน้าภาษาอังกฤษ [topology.md](../en/topology.md) (`--classes` · `--sat` · `--subdiv` · `--refine` · `--blur` · `--snap` · `--smooth` · `--corner` · `--target` · `--normals` · `--angle`)

## 4. สิ่งที่ลองแล้วไม่ได้ผล (จะได้ไม่เสียเวลา)

- **Voxel remesh แผ่นบาง**: ได้หลายหมื่นหน้า ช้า และยุบเส้นไม่ลง ซอยผิวแบบไม่ทำให้มนก็พอแล้ว
- **ขยับ / รวบจุดบนเส้นขอบสี** เพื่อลดจุด: ระนาบบิด ออกมาดู "เละ"
- **relax จุดด้านในแบบ retopo**: สามเหลี่ยมสวยขึ้นจริง แต่สันแบนลงและความแม่นตก
- **ระบายสีทีละแผ่นเล็กแล้วค่อยเกลี่ย**: ขอบสีเป็นขั้นบันไดที่เกลี่ยข้ามสันไม่ได้ แก้ด้วยการตัดตามเส้นชั้นของสี
- **บังคับทุกสีให้เป็นสีเดียวทั้งแผ่น**: ได้ผลดีกับลายนูน แต่ทำลายเส้นสีบางที่วาดไว้ ให้จำกัดด้วย `--snap`
